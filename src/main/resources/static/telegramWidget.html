Telegram Login Widget Test

Tests the real login endpoint (POST /api/auth/login/telegram) with whatever the widget hands back — same payload shape a real frontend would send (TelegramWidgetAuthRequest). Register-or-login: a Telegram account never seen before gets a brand-new Customer account created on the spot; one already linked (a returning customer, or a staff account that finished its invite) just logs in. Only a staff invite still pending phone-number verification gets an error here, same as a real client would see.
